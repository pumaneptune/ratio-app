# Eglin Labs Multi-Page Website

## Site Structure

### Pages
- **/** - Homepage with full product showcase
- **/products** - Detailed product information and capabilities
- **/pricing** - Pricing tiers (Basic Verify, DeFi Risk Verify, Execution Verify)
- **/docs** - API documentation and endpoint reference
- **/examples** - Guard code examples and integration snippets
- **/use-cases** - Use case scenarios for different agent types
- **/videos** - Demo video gallery with placeholders
- **/about** - Company information and mission
- **/contact** - Contact form and communication channels

### Navigation
- Sticky header with active page highlighting
- Mobile-responsive hamburger menu
- Quick access to API and GitHub in header

### Footer Links
- **Product**: Products, Pricing, Docs, API
- **Company**: GitHub, ACP Marketplace, Contact
- Social icons linking to GitHub, Contact, Docs, and ACP

### External Links
- **API Base**: https://decision-verification-agent.onrender.com
- **GitHub**: https://github.com/EglinLabs/decision-verification-agent
- **ACP Marketplace**: https://app.virtuals.io

### Design System
- Dark theme with retro 80s Atari/cyber terminal aesthetic
- Neon accent colors: Cyan, Emerald, Magenta
- Vector grid backgrounds
- Scanline effects
- Terminal-style panels
- Angular UI elements with custom clip-path
- Consistent hover states and transitions
- Fully responsive across all breakpoints

### Tech Stack
- React 18
- TypeScript
- React Router DOM
- Tailwind CSS
- Vite
- Lucide React Icons

### Key Features
- Client-side routing with React Router
- Animated terminal in hero section
- Retro arcade aesthetic with premium SaaS feel
- Comprehensive product information architecture
- Contact form for lead generation
- Video placeholder system for future content
- Code examples in terminal-styled panels
